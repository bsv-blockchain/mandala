## 3. Decisions the user approved (2026-10-05) — do not re-litigate

**Token-topic design** (spec, conversation):
- `tm_mandala` is the deploy-only token registry, with permanent records (the collection is `mandalaTokenRegistry`, because `mandalaRegistry` already holds KYC rows).
- `tm_<64-hex deploy txid>` / `ls_<same>` is one topic per token, with no `_0` suffix.
- The identity registry is renamed `tm_mandala_kyc` / `ls_mandala_kyc`.
- Widen BRC-87 upstream to `^(?=.{1,150}$)(?:tm_|ls_)[a-z0-9]+(?:_[a-z0-9]+)*$` (Q1).
- An operator follows the registry by default, with an optional `MANDALA_TOKEN_ALLOWLIST`.
- A deploy is one submit naming both `tm_mandala` and `tm_<own txid>`.
- `@bsv/overlay-topics` ships as **2.1.0**. This is the user's call, even though a reviewer noted that ts-stack `versioning.md` would ask for a MAJOR; the maintainer may rename it at publish.
- The Go overlay (`overlay-go/`, Mongo-only) is the stack. The TS `overlay/` is the parity reference only.

**Amendment A1** (spec §14):
- **Single overlay in Q3.** Cross-operator sync is deferred to a separate design, Q3b. GASP carries no envelope, and linkages are encrypted to one overlay's key, so a peer cannot verify ownership.
- **σI per topic.** σI is a per-topic map in one admission record. The digest becomes v3 and binds the topic: `SHA-256("mandala-admit:v3:" + topic + ":" + txid + ":" + join(sorted unique outs, ","))`.
- **Persisted refusals.** Final refusals are persisted for `tm_mandala` and `tm_<id>`; `tm_mandala_kyc` refusals are not.
- **Token list.** `GET /admin/tokens` is public and is the only wire for the token list.
- **Package path.** The Go package path is `internal/brc162`.

**Q3 plan choices** (the user said "OK with all"):
- **V-1:** a submit naming `tm_mandala` but not `tm_<own txid>` gets 400 `ERR_SHAPE`, before any write.
- **V-2:** the registry dry-run check runs before `Ensure`, so a refused deploy registers no topic.
- **V-3:** `MANDALA_TOKEN_ALLOWLIST=[]` hosts no token. Unset means follow every token.
- **V-4:** the `ERR_INPUT_SPENT` text uses the TS wording.
- **D-20:** after `Submit`, `/submit` re-reads the applied proof once for an empty σ-topic entry. No per-txid mutex.
- **D-1:** the old Go package is quarantined as `internal/mandalav2` until Task 25, so the build stays green.
